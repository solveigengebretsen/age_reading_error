This page contains the necessary analysis files for fitting the parametric age-reading error matrices for each of four age-reading exchange data sets, inspired by the ICES age reading guidelines. The method is presented and described in a scientific article, currently under review. The data sets will be available upon publication of the manuscript. 

The file analysis_NSAS_herring.r was used to analyse the otolith readings of North Sea Autumn-spawning herring. 

The file analysis_NSS_herring_otoliths.r was used to analyse the otolith readings of Norwegian Spring-spawning herring. 

The file analysis_NSS_herring_scales.r was used to analyse the scales readings of Norwegian Spring-spawning herring. 

The file analysis_atlantic_mackerel.r was used to analyse the otolith readings of Atlantic mackerel. 

The age-reading data are assumed to be in the same format as that of the SmartDots tool, that is:

Each row corresponds to an age-reading for one reader of each fish. 

The column "age" contains the read age. 

The column "expertise" contains an indicator for whether the reader is considered an expert reader (1) or not (0). 

The column "FishID" contains a unique identifier for each individual fish. 

In addition, the folder ECA_Mackerel_Otoliths contains the necessary files for applying the age-reading error matrix for otolith readings of Atlantic mackerel in estimated catch-at-age.
